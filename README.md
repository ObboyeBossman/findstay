# FindStay

FindStay is a school software-engineering project for a web-based accommodation marketplace and property-management platform. It is intended to help guests discover, book, and pay for accommodation while enabling property owners and managers to manage listings, availability, reservations, income, expenses, and reports.

## Key Deliverables & Presentation Assets

- `findstay-presentation.pptx`: The official 13-slide widescreen (16:9) presentation deck for the initial proposal defense, featuring FindStay branding, visual cards, embedded diagrams (ERD & User Workflow), and full embedded **speaker notes** on every slide for the defense team.
- `findstay-project-documentation.pdf`: The complete, illustrated 5-chapter academic project documentation (29 pages):
  1. Chapter One — Introduction (Background, Problem Statement, Objectives, Justification)
  2. Chapter Two — Literature Review and Existing-System Analysis (Competitive Matrix & Market Gap)
  3. Chapter Three — Requirements Analysis (Functional, Non-Functional, Domain Models)
  4. Chapter Four — System Design (3-Tier Java Spring Boot Architecture, Supabase-Style Visual ERD, Concurrency & Double-Booking Engine, End-to-End User Flowchart, Security Controls, and 5-Stream Revenue Model)
  5. Chapter Five — System Implementation, Testing, Deployment, and Conclusion
- `findstay-team-roles.pdf`: Dedicated 2-page Team Role Allocation document covering all 11 team members with simplified, student-friendly roles, specific module ownership, and signature sign-off sheet.
- `research/`: Synthesized academic research material, chapter drafts, and technical blueprints:
  - `FindStay_Team_Roles_and_Responsibilities.md` (11-member role allocation & governance)
  - `FindStay_Security_Architecture_and_Controls.md` (BCrypt, JWT, Paystack HMAC-SHA512, Ghana Act 843)
  - `FindStay_Revenue_Model_and_Financial_Sustainability.md` (5 revenue streams, unit economics table, break-even analysis)
  - `FindStay_Chapter_1_Synthesized_Draft.md` through `FindStay_Chapter_5_Synthesized_Draft.md`

## Project context

The project is focused on Ghana, with Takoradi as the proposed initial local context.
