# FindStay

FindStay is a school software-engineering project for a web-based accommodation marketplace and property-management platform. It is intended to help guests discover, book, and pay for accommodation while enabling property owners and managers to manage listings, availability, reservations, income, expenses, and reports.

## Current documentation

- `findstay-project-documentation.pdf` contains the official project documentation.
- `research/` contains the research material and synthesized drafts used to prepare the report.

## Project context

The project is focused on Ghana, with Takoradi as the proposed initial local context.
