# S1-03: Acceptance Criteria

- **Story:** [S1-03: Mobile & Desktop Page Layouts](./README.md)
- **Who this helps:** Small property owners, staff, and administrators on mobile phones and desktops
- **Priority:** Must have | **Track:** Track B | **Days:** D2–D5
- **Summary:** Build the shared Owner and Admin page layouts, menus, buttons, and status messages so every screen works cleanly on phones and desktops.
- **Screens involved:** Owner Portal shell (/owner), Admin Portal shell (/admin), mobile navigation, toast alerts, empty/loading/error states
- **Database tables:** None (UI layout and design components)
- **System actions:** Consistent error, empty, loading, and status feedback across all screens

## What Proves This Story Is Finished

1. Owner and Admin portal shells fit cleanly on small phones (360px), tablets, and desktops.
2. Navigation links, icons with text labels, buttons, and status messages look and behave consistently.
3. Screens work across Chrome, Edge, Firefox, and Safari with no horizontal scrolling at 360px.
