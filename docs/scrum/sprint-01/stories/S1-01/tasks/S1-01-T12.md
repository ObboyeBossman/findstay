## What this task really means

You set up the testing tool that gives every automated test its own fresh, real database for a few seconds and then throws it away — so tests prove real behaviour instead of pretending. You also set the rule that every test is labelled with the requirement number it proves. After your work, any teammate can write trustworthy tests, and at any moment the team can see which requirements are actually proven.

## What you will have at the end

- Any teammate can write a test that runs against a real throwaway database and cleans up after itself.
- Every test labelled with the requirement it proves, so coverage is visible at any moment.
