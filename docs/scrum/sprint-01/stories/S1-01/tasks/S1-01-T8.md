## What this task really means (plain English)

You draw the Entity-Relationship Diagram (ERD) — the picture of the database: every table the system will have, what each table stores, and how the tables connect to each other (for example, one owner can have many properties). This diagram is the agreed design that the real database is built from, so the whole team reviews it before any table is created.

## What you will have at the end

- The Entity-Relationship Diagram (ERD) covering all Sprint 1 data: every table, its columns, and how tables connect.
- A reviewed and agreed diagram that the real database (T9) is built directly from.
