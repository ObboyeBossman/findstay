## What this task really means

You turn the agreed user journeys into simple grey sketches of every screen — where the button goes, where the list goes — with no final colors yet. You draw each screen for a small phone first (360px wide), then show how it stretches onto a desktop. After your work, the team can agree the layout of every screen before real interface code starts.

## What you will have at the end

- A wireframe sketch for every Sprint 1 screen, phone-first (360px) with the desktop variant.
- Each sketch labelled with what every element does, ready for team sign-off before UI code starts.
