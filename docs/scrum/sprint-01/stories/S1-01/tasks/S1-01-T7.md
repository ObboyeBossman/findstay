## What this task really means

You create the empty server application and put in the standard pieces every future feature will need: how money is stored (in pesewas, as whole numbers — never floating decimals), how dates are kept (UTC) and displayed (Ghana time), the standard shape of error messages, how records get their IDs, and the background-job helper. After your work, feature teams never have to reinvent these — they just use them.

## What you will have at the end

- A running, empty server app with the shared pieces built in: pesewa money, UTC storage with Ghana-time display, standard errors, IDs, events, background jobs.
- Tests proving those shared pieces work — feature teams just use them.
