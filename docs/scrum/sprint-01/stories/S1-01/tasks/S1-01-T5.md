## What this task really means

You create the empty FindStay website app: it opens and runs in a browser, its three separate areas (guest, owner/company, admin) are already wired so each opens its own pages, and each feature has its own folder ready. This is the shell your teammates will fill — nobody builds screens until your shell exists.

## What you will have at the end

- An empty but working website: the guest, owner and admin areas each open their own pages.
- One folder per feature, plus simple run instructions, so teammates can build screens inside it immediately.
