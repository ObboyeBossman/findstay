## What this task really means

You draw the journey a person takes from one screen to the next until their job is done — for example a guest searching and booking a room, an owner adding a listing, an admin approving it. You also draw what happens when something goes wrong (wrong password, no internet) and when there is nothing to show yet (an empty list). After your work, everyone can see exactly which screens exist and how they connect, before any code is written.

## What you will have at the end

- User flow diagrams: one drawing per journey, every screen as a box, arrows for every path.
- Error paths and empty states drawn too — so developers know every screen to build and how they connect.
