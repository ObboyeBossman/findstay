# FindStay Typography

The interface pairs **Roboto** for display and headings (Medium 500, Bold 700, Black 900) with **Work Sans** for UI labels and body copy (Regular 400, Medium 500, Bold 700).
The type scale is **1.250 (Major Third)**.

## Shared styles

| Style | Font | Weight | Size | Line height |
| :--- | :--- | :--- | :--- | :--- |
| Subtitle | Work Sans | Medium (500) | 20px | 140% |
| Label | Work Sans | Medium (500) | 16px | 140% |
| Body 1 | Work Sans | Regular (400) | 20px | 150% |
| Body 2 | Work Sans | Regular (400) | 16px | 140% |

Use the corresponding `.text-*` class from `web/src/typography.css` (or Tailwind `font-display` / `font-sans` utilities) for each style. The default body text is Body 2 (`Work Sans` Regular).
