# 03 — Architecture, Stack & Security Rules

## 1. Approved Technology Stack

- **Frontend (`web/`):** React + TypeScript + Vite deployed to **Cloudflare Workers Static Assets**. Responsive mobile-first web UI (`NFR-09`, `NFR-12`).
- **Backend (`api/`):** **Java 21 + Spring Boot 3** modular monolith (`Spring Modulith`) deployed on **Render**.
- **Database:** **Render PostgreSQL** (PostgreSQL 16+), migrated exclusively by **Flyway** in `api/src/main/resources/db/migration/V1_01..V1_19`.
- **Object Storage:** **Cloudflare R2** (`findstay-property-images` public bucket via Cloudflare CDN for `WebP` photos; `findstay-verification-docs` private bucket accessed via short-lived pre-signed URLs issued by `api/`).
- **Authentication:** **Supabase Auth** (`@supabase/supabase-js` in `web/` for sign-up, OTP, password recovery, and 1-hour JWT issuance; verified in `api/` via Supabase JWKS).

---

## 2. Data Access & Authentication Boundaries

1. **Zero Direct Frontend Database Access (`TA-01`, `TA-02`):** The browser talks to Supabase **only** for Auth (`supabase.auth.*`). All business data reads/writes and Cloudflare R2 pre-signed URL requests go through the Spring Boot REST API (`/api/v1/...`).
2. **JWT Verification via JWKS (`TA-08`):** The Spring Boot resource server validates every incoming `Authorization: Bearer <token>` against Supabase's JWKS endpoint and maps the authenticated user's active organisation membership and role permissions into the request security context.
3. **Multi-Tenant Isolation (`OrgScope`, `J-06`):** Every owner's properties, units, documents, bookings, and staff memberships belong to an `organization_id`. Repository queries and service methods must enforce `OrgScope` so Owner A can never read or mutate Owner B's records.

---

## 3. Domain & Data Integrity Conventions

1. **Money in Integer Pesewas:** All monetary amounts (rates, fees, payouts, refunds) are stored and calculated as `BIGINT` integer **pesewas** (`1 GHS = 100 pesewas`) paired with `currency = 'GHS'`. Floating-point types (`FLOAT`, `DOUBLE`) are forbidden for money.
2. **Time in UTC, Displayed in `Africa/Accra` (`NFR-52`):** All timestamps are persisted as `TIMESTAMPTZ` in UTC and formatted in `Africa/Accra` (`GMT+0`) at the presentation boundary.
3. **Append-Only Audit Trail (`S1-08`):** Sensitive actions (role changes, verification decisions, listing approvals/rejections, account suspensions/restorations) must write an immutable record via `AuditRecorder`. Audit rows cannot be updated or deleted by application users.
4. **Encryption & PII Protection (Ghana Act 843):**
   - TLS 1.2+ in transit for all endpoints (`NFR-21`).
   - Government ID numbers (Ghana Card numbers) are encrypted at rest with AES-256 before persistence (`NFR-28`, `TA-09`).
   - Verification documents and property deeds are stored in the private Cloudflare R2 bucket and accessed only via short-lived pre-signed URLs generated by `api/` after authorization checks (`NFR-24`).
   - Images uploaded for listings are validated for MIME/size limits (`<= 5 MB`) and served as optimized `WebP` (`TA-13`, `NFR-17`).
