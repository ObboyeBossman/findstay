## 3. Summary of Member Responsibilities

1. **Bossman Abraham - N. O. (BC/ITS/24/197) — Project Leader**  
   Oversees the entire project from start to finish. Keeps track of milestones and ensures all parts are integrated smoothly for the final presentation.

2. **Joseph Osei-Bonsu (BC/ITS/24/168) — Backend Developer**  
   Focuses on the Java Spring Boot backend. Writes the code that checks room availability, handles reservations, and prevents double-bookings.

3. **David Ofori (BC/ITS/24/263) — Frontend Developer**  
   Focuses on the user-facing website using React. Makes sure the search filters, room photos, and booking pages look clean and work on phones and laptops.

4. **Solomon Fummey (BC/ITD/24/014) — Database Designer**  
   Creates and manages the PostgreSQL database tables for users, properties, rooms, bookings, payments, and expenses so data is saved safely.

5. **Emmanuel Rockson (BC/ITN/24/153) — Deployment & Hosting**  
   Handles the hosting setup. Puts the frontend website on Vercel and the Java backend server on the cloud, making sure the project is accessible online.

6. **Sampson Badu (BC/ITS/24/161) — Payment Integration**  
   Implements Mobile Money payments with Paystack. Ensures guests can pay easily with MTN, Telecel, or AT and get instant digital receipts.

7. **Seidu Afeadzi (BC/ITS/24/152) — System Security**  
   Manages user login and security. Encrypts passwords so they cannot be stolen, and makes sure guests and owners only access their own accounts.

8. **Mashkura Tahiru (BC/ITS/24/265) — Property Management Module**  
   Builds the owner portal. Enables property owners to manage room availability, check guests in, and log daily expenses to calculate monthly profit.

9. **Anthony Maclean (BC/ITS/24/151) — Booking & Reservation Module**  
   Handles the reservation lifecycle. Ensures booking steps from request to confirmation, expiration timers, and cancellation policies work smoothly.

10. **Bright Afedi (BC/ITS/24/156) — System Testing**  
    Responsible for testing the system. Tests buttons, search filters, and booking flows to find and fix any bugs before final project submission.

11. **Okyere Ankomah - Julius (BC/ITS/24/164) — Project Documentation**  
    Prepares the written documentation. Compiles the project requirements, design chapters, user guides, and makes sure the final report is organized.
